# 玩偶合成

现行只做了源文件里**带配方图的 13 只**。其余 28 只没有合成。头颅生成器仍然无合成。

图在 `模型工程文件/源文件/`。原版配方认不出玩家名和烟花时长，所以用 Fabric 自定义材料：`bcs_furnishings:player_head`（按名字，大小写不敏感）、`bcs_furnishings:firework_rocket`（只要飞行时长，不管有没有爆炸）。头生成器弹出来的头能用。拿到任意玩家头会解锁这 13 条配方书。

JSON：`data/bcs_furnishings/recipe/`。产出都是 1 个。
