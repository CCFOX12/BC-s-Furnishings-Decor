## grilling 拍板

做之前先问了合成：创造栏拿，无合成，红石无限弹出同一个头。

### 第 1 轮

- **身份：** 服主/地图工具，创造栏能拿，不算卖点。
- **红石：** 和投掷器一样，上升沿打一次，一直亮不连发。
- **输出：** 永远弹成地上的物品实体，正面有箱子也不塞。
- **GUI：** 不用铁砧底图，一块小面板 + 输入框。
- **朝向：** 只水平四向，vertical 贴图不用。
- **失败：** 空名、非法字符、查无此人、断网都不出头，只播投掷器空仓音。不发 Steve 头。
- **改名：** 右键还能改，下次脉冲用新名。

### 第 2 轮

- **谁能改名：** 只有 OP（权限等级 2）能开 GUI。红石触发不限 OP。
- **创造栏：** 本模组单独「功能」页，不进红石页、不进玩偶页。
- **拆了：** 掉落空方块，名字丢。
- **玉：** 显示已存玩家名。
- **空框关掉：** 清掉存的名字，下次脉冲只播失败音。
- **比较器：** 不做。
- **GUI 贴图：** 不新画图，用原版控件搭小面板。工程里当时没有 GUI 图。

### 第 3 轮

- **非 OP 右键：** 没反应，不提示。手里方块仍可贴着放。
- **创造 Ctrl+中键：** 取出来也是空方块。
- **物品 tooltip：** 两行——仅 OP 可设置；红石弹出正版玩家头颅。
- **单人开界面：** 不暂停，像箱子 GUI。

收口：就这样，按这个做。

## 玩家侧

- 中文名「头颅生成器」。创造栏「功能」。叠 64。稿子敲，硬度 3.5，石头手感。
- 放下按玩家当时水平朝向转面，正面朝玩家。
- 只有 OP（`Permissions.COMMANDS_GAMEMASTER`）能右键开界面。非 OP 右键 `PASS`，不开、不提示。
- 小面板 + 输入框，maxlen 16，只许 `A-Za-z0-9_`。关掉写回；空框清名。输入框聚焦时按 E 不关窗。
- 红石上升沿打一次。成功从正面弹出该正版玩家头颅（出射点中心沿朝向 0.7 格）。失败只播空仓音。
- 拆了或中键取出都不带名字。
- 玉：有存名显示玩家名；空名不加第二行。
- 服务器要能访问 Mojang 会话服务。同一名字可无限弹。

## 代码

包 `cc.fox.bcsfurnishings.headgenerator`，客户端 `cc.fox.bcsfurnishings.client.headgenerator`。不走 GeckoLib。

- `HeadGeneratorBlocks`：方块、物品、BE、创造栏、payload 注册。入口 `BcsFurnishings.onInitialize`。
- `HeadGeneratorBlock`：四向 + `TRIGGERED`；OP 发 S2C 开界面；`getCloneItemStack` 永远干净物品；脉冲 `ProfileResolver.fetchByName`。
- `HeadGeneratorBlockEntity`：NBT `PlayerName`；`getUpdatePacket` 同步客户端。
- `HeadGeneratorBlockItem`：两行 tooltip。
- 开界面 S2C `bcs_furnishings:head_generator_open`；关界面 C2S `bcs_furnishings:head_generator_set_name`。服务端再验 OP 和距离。
- 头颅：`Items.PLAYER_HEAD` + `ResolvableProfile.createResolved`。弹出：`DefaultDispenseItemBehavior.spawnItem` + 音效 1000 + 粒子 2000。失败 1001。
- 客户端：`HeadGeneratorClient` 收开界面包；`HeadGeneratorScreen`（`isPauseScreen` false）。
- 玉：`HeadGeneratorJadeProvider`，在 `DollJadeClient` 里一并注册。
- 掉落：`data/bcs_furnishings/loot_table/blocks/head_generator.json`（不 copy 组件）。稿子：`data/minecraft/tags/block/mineable/pickaxe.json`。
