# 玩偶发光灯

已转正。以后改行为以本文和 [玩偶规格.md](玩偶规格.md) 为准。

普通玩偶仍是方块光照 0、右键无互动。带发光灯的那只多两件事：贴图自发光，放置后能开关。不另做方块、不另开渲染器。

现行只有 **`alittle_bird_sit`**（`ALittle_bird_sit`）。再加一只按文末步骤，不要给没 glowmask 的玩偶抄发光层。

## 玩家侧

- 放下默认灯是开的。
- 对着放下的这只右键：开 ↔ 关。空手、手里拿着东西都算。潜行右键不开关，方便贴着它放方块。
- 开着：glowmask 上的像素全亮，方块光照 **15**（和灯笼一样）。关掉：自发光和光照都停，模型还在。
- 声音用铜灯开/关。
- 手持、掉落、戴头不走开关，一直按开着画。拆了再放下，又是开着。
- tooltip 多一行「放置后右键开关灯」。玉仍只写可戴外观头槽。
- 其它玩偶右键仍没互动，光照仍是 0。

不做：红石开关、比较器、拆了记住开关、头上再切一次。

## 贴图

正本是 glowmask，不是运行时扫颜色。

```
模型工程文件/模型资产/ALittle_bird/ALittle_bird_sit_glowmask.png
assets/bcs_furnishings/textures/block/alittle_bird_sit_glowmask.png
```

GeckoLib 约定：基础贴图 `foo.png` → `foo_glowmask.png`。只留要亮的像素，其余全透明。

第一只灯芯是从 `alittle_bird_sit.png` 里抽出 `#fff200`（含同色块边缘 2 像素）。新玩偶在 BB 里画 glowmask，不要再靠扫色。

## 光影

GeckoLib 默认 `geckolib:pipeline/emissive` Iris 不认，开 Photon 会整层丢掉。发光层走原版 `RenderTypes.eyes`（`RenderPipelines.EYES` → `gbuffers_spidereyes`）。关光影也是蜘蛛眼那套全亮。

## 代码

- 全员 `DollBlock` 都有方块状态 `LIT`（默认 true）。blockstate JSON 八个变体（四向 × 开/关），模型相同，GeckoLib 照样画。
- 只有 `glowLamp == true` 的那只：`lightLevel` 在 `LIT` 时为 15；`useWithoutItem` / `useItemOn` 切 `LIT`。id 目前写在 `DollBlock.GLOW_LAMP_ID`。
- 客户端 `AlittleBirdSitGlowLayer` 挂在共用的方块/物品渲染器上。贴图不是这只就返回 null，其它玩偶不会去找 `_glowmask`（缺文件会紫块）。放置且 `LIT=false` 时也不画发光层。
- 物品渲染器只给 `alittle_bird_sit` 加这一层。

## 再加一只

1. 导出同名 PNG 的 glowmask，拷进工程目录和 `textures/block/<id>_glowmask.png`
2. `DollBlock.GLOW_LAMP_ID` 改成能覆盖多只，或等价名单；`lightLevel` 只给名单里的亮
3. 发光层按贴图路径放行，不要无条件 `AutoGlowingGeoLayer`
4. 物品 tooltip 走 `DollBlock.isGlowLamp()`，已有「放置后右键开关灯」
5. 进游戏：放下默认亮、右键能关、关了房间变暗、潜行能贴着放、开 Photon 仍亮、其它玩偶不变
