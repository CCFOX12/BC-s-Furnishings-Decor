# 项目基线

下一轮对话以本文和 `开发流程/00-立项与版本节奏.md` 为准。

## 版本

| 项 | 值 |
| --- | --- |
| Minecraft | 1.21.11 |
| Fabric Loader | 0.19.5 |
| Fabric API | 0.141.6+1.21.11 |
| Java | 游戏 / 模组字节码 21；Gradle / Loom 1.19 要用本机 JDK 25 |

| 映射 | `loom.officialMojangMappings()`；不要写成 26.x 无混淆 |

## 玩家必装

- Fabric API `0.141.6+1.21.11`
- Trinkets Updated `3.11.0-beta.2+1.21.11`（beta；游戏内 id 仍是 `trinkets`）
- Cosmetic Armor Updated `1.7.0`（1.21.11，id `cosmeticarmor`）
- Cardinal Components API `7.3.2`
- GeckoLib `5.4.5`（玩偶 `.geo.json`；时装贴图不靠它）

具体坐标和怎么启动见 [开发环境.md](开发环境.md)。

JEI、玉（Jade）不是必装。装了必须：合成能查、对着玩偶能看到中文名和「可戴外观头槽」。对着头颅生成器时，有存名要能看到玩家名。

## v1 做什么

- 小型纯方块玩偶：能放、四向朝向、破坏收回、戴外观头槽。实现以 [玩偶规格.md](玩偶规格.md) 为准，新加的也同一套。部分玩偶可带发光灯（自发光 + 放置后开关），见 [玩偶发光灯.md](玩偶发光灯.md)
- 时装：外观头/身/腿/脚，无战斗数值，真护甲保留
- 每件一条原版材料合成
- 入仓后能进游戏的成品都进 v1；不强求同一主题
- 现有 Blockbench 工程在 `模型工程文件/`

## v1 不做什么

- 家具（含展示底座）
- NPC、抽奖、盲盒、投掷实体、捏捏叫、360° 微调
- 自研饰品槽、AzureLib、Accessories 非官方移植

## 另有创造工具

头颅生成器在创造栏「功能」页，无合成，不算 v1 卖点。仅 OP 可设置名字，红石弹出正版玩家头颅。口径见 [头颅生成器.md](头颅生成器.md)。
