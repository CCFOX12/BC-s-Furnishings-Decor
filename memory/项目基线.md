# 项目基线

下一轮对话以本文和 `开发流程/00-立项与版本节奏.md` 为准。

## 版本

| 项 | 值 |
| --- | --- |
| Minecraft | 1.21.11 |
| Fabric Loader | 0.19.5 |
| Fabric API | 0.141.6+1.21.11 |
| Java | 21 |
| 映射 | 1.21.11 仍用 Loom 重映射；不要写成 26.x 无混淆 |

## 玩家必装

- Fabric API `0.141.6+1.21.11`
- Trinkets Updated（1.21.11 线目前是 beta）
- Cosmetic Armor Updated
- Cardinal Components API（Cosmetic Armor 在 1.21.11 需要）
- GeckoLib（玩偶 `.geo.json`；时装贴图不靠它）

JEI、玉（Jade）不是必装。装了必须：合成能查、对着玩偶能看到中文名和「可戴外观头槽」。

## v1 做什么

- 小型纯方块玩偶：能放、四向朝向、破坏收回、戴外观头槽
- 时装：外观头/身/腿/脚，无战斗数值，真护甲保留
- 每件一条原版材料合成
- 入仓后能进游戏的成品都进 v1；不强求同一主题
- 现有 Blockbench 工程在 `模型工程文件/`

## v1 不做什么

- 家具（含展示底座）
- NPC、抽奖、盲盒、投掷实体、捏捏叫、360° 微调
- 自研饰品槽、AzureLib、Accessories 非官方移植
