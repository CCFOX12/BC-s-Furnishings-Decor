# 时装规格

贴图覆盖时装的现行实现。grilling 计划 `fashion_overlay_pipeline`。3D 饰品只在本文留口，这轮没有代码。

测试 4 件已进创造栏「时装」。无合成。

## 玩家侧

- 一张 64×64 玩家皮肤 PNG = 一件物品。不透明像素覆到玩家皮肤上，不按槽裁 UV。
- 创造栏「时装」。叠 64。一行灰字：「外观，不提供防御」。
- 对着空气右键进 Cosmetic Armor 对应外观槽（Trinkets `head/chest/legs/feet` 的 `cosmetic`）。真护甲不动。生存扣 1，创造复制。同槽已有的互换。戴上播原版 generic 护甲音。
- 原版护甲槽放不进（`ArmorSlotMixin` 拒 `bcs_furnishings:fashion`）。
- 自己、F5、别人、物品栏纸人、第一人称手都用烘焙皮。披风这轮不管。
- 玩家皮肤自定义里关了帽子/外套，时装对应第二层也不画。
- 头饰和玩偶抢同一外观头槽，自然互斥。套装不占头槽，可以和头上玩偶同时。

## 后缀和槽

文件名末尾限定词，前面的玩家名/主题不动。

| 后缀 | 中文 | 英 | 槽 |
| --- | --- | --- | --- |
| `_head` | 头饰 | Head | `head/cosmetic` |
| `_top` | 上装 | Top | `chest/cosmetic` |
| `_bottom` | 下装 | Bottom | `legs/cosmetic` |
| `_shoes` | 鞋饰 | Shoes | `feet/cosmetic` |
| `_set` | 套装 | Set | `chest/cosmetic`（独占另外三槽） |

套装和上装同胸槽，自然互换。穿上套装时把头/腿/脚槽里的**时装**弹回背包（满了掉脚边）；套装还在时再穿头饰/下装/鞋饰则拒绝，只播拒绝音，不喊话。头上玩偶不当时装，不弹。

分体混搭叠图：脚 → 腿 → 胸 → 头，后画盖住先画。

## 第二层打孔

第一层和第二层在皮肤 UV 上不是同一格，按部位矩形配对逐像素，不能整张 +32。

| 第一层 | 第二层 |
| --- | --- |
| 头 `(0,0) 32×16` | 帽子 `(32,0) 32×16` |
| 右腿 `(0,16) 16×16` | 右裤 `(0,32) 16×16` |
| 身 `(16,16) 24×16` | 外套 `(16,32) 24×16` |
| 右臂 `(40,16) 16×16` | 右袖 `(40,32) 16×16` |
| 左腿 `(16,48) 16×16` | 左裤 `(0,48) 16×16` |
| 左臂 `(32,48) 16×16` | 左袖 `(48,48) 16×16` |

规则：

1. 时装第一层不透明：写入玩家第一层。
2. 时装第二层不透明：写入玩家第二层。
3. 时装第一层不透明、同部位第二层透明：清掉玩家第二层该像素。
4. 两层都透明：玩家原像素不动。
5. 第一层透明、第二层不透明：只写入第二层（帽子/外套叠在原皮上）。

`alpha >= 8` 当不透明，整格替换，不和原皮混合。64×32 老皮按原版拉成 64×64；更大的高清皮先缩到 64×64。测试件按宽臂 Steve；Alex 细手臂这轮不单独映射，错位接受。

## 代码

- 包 `cc.fox.bcsfurnishings.fashion`，客户端 `cc.fox.bcsfurnishings.client.fashion`。
- `FashionKind.TEXTURE` 走贴图覆盖；`MODEL` 枚举留下，注册时跳过。
- 物品是普通 `Item` + `Equippable`（无护甲 asset），不是 `ArmorItem`。
- 烘焙在 `AvatarRendererMixin.extractRenderState` 末尾换成 `PlayerSkin` body。缓存 key = 皮肤 id + 四槽物品。Iris 仍走原版玩家皮肤 RenderType。
- Cosmetic Armor 若把时装当护甲画：`HumanoidArmorLayer.shouldRender` 跳过 `bcs_furnishings:fashion`。头槽时装清掉 `headItem`。
