# 玩偶入仓与基础功能

归档自执行计划 `doll_import_execute` 与 grilling 计划 `doll_assets_and_basics`。资产路径以本轮实际为准。

现行实现、以后加玩偶怎么做：见 [玩偶规格.md](玩偶规格.md)。本文只保留入仓当时的拍板和 41 只名单。

## 资产路径（本轮）

预处理正本：`模型工程文件/模型资产/`（41 对 `.geo.json` + `.png`，按玩家文件夹）。不走 `assets-incoming/`，不移动、不真删 `模型工程文件/`。

封面：`模型工程文件/mod图标/图标.jpg`（原 jpg 留着）。游戏用 PNG：`src/main/resources/assets/bcs_furnishings/icon.png`，`fabric.mod.json` 的 `icon` 指向它。

拷进模组后：

- `assets/bcs_furnishings/geckolib/models/block/<id>.geo.json`
- `assets/bcs_furnishings/textures/block/<id>.png`
- 共用空动画：`assets/bcs_furnishings/geckolib/animations/block/doll_empty.animation.json`

GeckoLib 5.4.5 认 `format_version: 1.21.0`。抽查 `AaBo_duck_sit.geo.json` 已是这个版本；`group_photo.geo.json` 仍是 `1.12.0`，交给 GeckoLib 加载。

## grilling 拍板

### 第 1 轮

- **geo 谁出：** 你在 Blockbench 里 Convert + Export 全部 41 套 `.geo.json` + PNG。我们不自动转，不从 bbmodel 抽贴图当正本。
- **商品数：** 41 个文件 = 41 个独立玩偶。特别版 / 女仆 / 奶龙都单独进创造栏。
- **戴头：** 整只缩小坐在头顶，同一套摆件 geo，不做 Armor 骨架。
- **超高模型：** 全收。碰撞统一小盒子（约 1 格或更矮），视觉可以冒出方块。
- **真头盔：** mixin 硬拒 `dolls` 物品标签，外观头槽能戴，原版头盔槽放不进。

### 第 2 轮

- **节奏：** 成对出现 geo+png 就进注册表。本轮 41 对已齐，全部注册。
- **摆正：** 导出前在 Blockbench 里摆正。放置后面朝玩家当时水平看的方向（四向）。
- **物品栏/手上：** 同一套 3D geo，不用皮肤 PNG 当 2D 图标。
- **头上倍率：** 全体一个常数，约 0.45。
- **穿模型：** 接受。碰撞仍是小盒子。
- **中文名：** 文件名当草稿。以后改 `zh_cn.json`。

### 第 3 轮

- **Display：** 只导 geo+png。背包/手的远近旋转全体同一套。
- **手感：** 羊毛（手可敲、软声）。
- **堆叠：** 64。
- **创造栏顺序：** 按 `模型资产` 的文件夹分组排。

### 第 4 轮

- **火：** 不烧。声音/硬度像羊毛，但不是燃料、不会被火点燃。
- **其余：** 爆炸抗性偏低（同羊毛）；有方块实体，活塞推不动；不含水；不能当头盔附魔；不发光。

## 代码（全员同一套）

- `DollCatalog`：按 `模型资产` 文件夹顺序列 41 条。
- `DollBlock`：水平四向；羊毛声/硬度；不燃；小碰撞箱；掉落自己。
- `DollBlockEntity` + 一个 `BlockEntityType` 覆盖全部玩偶；空动画控制器 + 共用空 animation。
- 客户端：`GeoBlockRenderer`（`software.bernie.geckolib`）；`DollBlockItem` 实现 `GeoItem`，背包/手 3D。
- 物品变换只写在 `models/item/doll_item.json`，41 个 id 继承它。GUI `[30, 225, 0]` + 下移 7。第一人称右手 `[0, 135, 0]`、左手 `[0, 315, 0]`。掉落物 `ground` 0.5。`display.head` 缩放 1（头上倍率由渲染层 0.625 翻转负责）。
- 戴头：空中右键进 Cosmetic Armor 外观头槽（Trinkets `head/cosmetic`），真头盔留着；对着方块仍放置。生存扣 1、创造不扣，槽内互换，羊毛放置音。原版头盔槽 mixin 仍拒收。盔甲架本轮不做。
- 头上：森罗翻转（Y 180°、scale 0.625/-0.625/-0.625），Y 平移 `-0.5`（坐姿底面落到头顶，不是头骨中间）。跟着头骨点头；第一人称世界不画，物品栏角色缩略图要画。读 `CosmeticArmor.getCosmeticArmor(entity, HEAD)`。Cosmetic Armor 会把外观头塞进 `headItem`，外观槽或原版头槽是玩偶都要清掉，只留我们的层。抽取打在 `AvatarRenderer.extractRenderState(Avatar, …)`，不是 LivingEntity 桥接方法。头上走 `ItemStackRenderState`，GeckoLib 的 `(0.5, 0.51, 0.5)` 要留着，用来对消原版 `ItemTransform` 末尾的 `-0.5`。
- 创造栏「玩偶」；玉：中文名 + 模组名 + 「可戴外观头槽」。

入口：`BcsFurnishings` / `BcsFurnishingsClient`。
