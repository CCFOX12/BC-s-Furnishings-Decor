# 玩偶规格

全员同一套。现有 41 只和新加的都按这份，不准给某一只另写行为、另设头上倍率或另做物品变换。

名单和入仓经过见 [玩偶入仓与基础功能.md](玩偶入仓与基础功能.md)。玩法需求见 `开发流程/02`。

## 玩家侧

- 纯方块摆件。破坏收回自己。叠 64。创造栏「玩偶」。
- 放下按玩家当时水平朝向转面，四个方向，和发射器一样（面朝玩家）。
- 碰撞是中间一块小盒子（`3–13` / `0–10` / `3–13`，像素）。模型可以冒出盒子，包括超高的。
- 羊毛手感：声音、硬度 `0.8`、地图色羊毛。不燃。活塞推不动。不含水。默认不发光（方块光照 0）。带发光灯的那只见 [玩偶发光灯.md](玩偶发光灯.md)。
- 对着空气右键：戴进 Cosmetic Armor 外观头槽（Trinkets `head/cosmetic`）。真头盔不动。槽里已有的互换。生存扣 1，创造复制不扣。戴上播羊毛放置音。
- 对着方块右键：仍是放置，不走戴头。
- 原版头盔槽放不进（`ArmorSlotMixin` 拒 `bcs_furnishings:dolls`）。
- 头上是整只缩小坐在头顶，同一套摆件 geo，不做 Armor 骨架。跟着头点头。第一人称世界不画。F5 / 别人 / 物品栏角色缩略图都看得到。
- 物品 tooltip、玉：中文名 + 模组名 +「可戴外观头槽」。
- 外观头槽同时只能一件：戴着时装头饰就不能再戴玩偶，反过来一样。套装走胸槽，可以和头上玩偶同时。时装细则见 [时装规格.md](时装规格.md)。

显示名：玩家名原文保留。后缀按文件名顺序空格接上；先认整段 `_sit_2`，再认单独 `_sit`，不要写成「坐姿 坐姿2」。

## Blockbench

你出 `.geo.json` + PNG，用插件 **GeckoLib Models & Animations** Convert + Export。不要自动转、不要从 bbmodel 抽贴图当正本。

导出前摆正，约定：

| 项 | 规格 |
| --- | --- |
| 原点 | 坐姿底面中心。坐标轴原点贴在屁股/腿接触地面的点，XZ 居中，不要在身体里或模型角落 |
| +Y | 朝上 |
| 正面 | 放置后面朝玩家；导出前转好，进游戏不再单只要朝向修正 |
| 缩放 | 按摆件实际大小导出。头上、背包、掉落的倍率全员共用，不要在模型里预缩一版「头饰尺寸」 |
| 贴图 | 和 geo 同名的一张 PNG |
| 格式 | `format_version` 优先 `1.21.0`；`1.12.0` 也能加载 |
| 动画 | 不写。游戏用共用空动画 `doll_empty` |

头上能坐实，靠原点在底面。Java 把原点放到玩家头顶，不再给每只写偏移。某只悬空或歪到一边，回 BB 把原点挪到坐姿底面中心再导出，不要改 `HEAD_SIT_Y`。

工程文件留在 `模型工程文件/`。游戏不读那边。不要真删，要挪就进 `已删除文件/`。

## 资源路径

注册 id = 文件名全小写。`AaBo_duck_sit` → `aabo_duck_sit`。双下划线保留。

拷进模组（复制，不移动工程目录）：

```
assets/bcs_furnishings/geckolib/models/block/<id>.geo.json
assets/bcs_furnishings/textures/block/<id>.png
```

每只再套同一套 JSON（照现有任意一只抄，只改 id）：

| 文件 | 作用 |
| --- | --- |
| `assets/bcs_furnishings/items/<id>.json` | `minecraft:special` + `geckolib:geckolib`，`base` 指向下面的 item 模型 |
| `assets/bcs_furnishings/models/item/<id>.json` | parent：`bcs_furnishings:item/doll_item` |
| `assets/bcs_furnishings/models/block/<id>.json` | 只有 particle 贴图；方块本身 `INVISIBLE`，GeckoLib 方块实体画 |
| `assets/bcs_furnishings/blockstates/<id>.json` | 四向 × `lit` 开/关，都指向同一个 block 模型。朝向由方块实体转 |
| `data/bcs_furnishings/loot_table/blocks/<id>.json` | 破坏掉自己 |
| `data/bcs_furnishings/tags/item/dolls.json` | 加上 id |
| `data/bcs_furnishings/tags/block/dolls.json` | 加上 id |
| `lang/zh_cn.json`、`lang/en_us.json` | `block.bcs_furnishings.<id>` |

物品变换只写在 `models/item/doll_item.json`，41 只和新加的都 inherit，不要给单只要 `display`。

| 槽 | 现行值 |
| --- | --- |
| gui | 旋转 `[30, 225, 0]`，平移 `[0, -7, 0]`，缩放 `0.625` |
| ground（掉落） | 平移 `[0, 3, 0]`，缩放 `0.5`（放置视觉的一半） |
| head | 平移 `0`，缩放 `1`（头上倍率在渲染层，避免叠乘） |
| thirdperson | 旋转 `[75, 45, 0]`，平移 `[0, 2.5, 0]`，缩放 `0.375` |
| firstperson 右 | 旋转 `[0, 135, 0]`，缩放 `0.4` |
| firstperson 左 | 旋转 `[0, 315, 0]`，缩放 `0.4` |
| fixed | 旋转 `[0, 180, 0]`，缩放 `0.5` |

## 注册

`DollCatalog.ENTRIES` 按 `模型工程文件/模型资产` 的文件夹顺序追加一行：

```java
entry("文件夹名", "文件名stem")
```

`stem.toLowerCase()` 就是注册 id。不要新建 `DollBlock` 子类、不要新 BlockEntityType、不要新 FeatureRenderer。

共用代码（加玩偶时不要改这些来「适配这一只」）：

- `DollBlock` / `DollBlockItem` / `DollBlockEntity`（全员有 `LIT`；只有发光灯那只用它开关和发光）
- `DollItemRenderer` + `DefaultedBlockGeoModel`（block 路径的 geo）
- `DollHeadFeatureRenderer`、`DollClientData`
- 发光灯：`AlittleBirdSitGlowLayer` + `_glowmask.png`，细则 [玩偶发光灯.md](玩偶发光灯.md)
- `ArmorSlotMixin`、`AvatarRendererMixin`、`LivingEntityRendererMixin`
- 标签 `bcs_furnishings:dolls`

物品带 `Equippable.HEAD`（`setDamageOnHurt(false)`），Cosmetic Armor 才收进外观头槽；真头盔槽仍被 mixin 拒收。

## 头上（全员共用）

常数在 `DollClientData`：`HEAD_SCALE = 0.625`，`HEAD_SIT_Y = -0.5`。`group_photo_xd` 也走这套，不准例外。

渲染层：

1. `root().translateAndRotate` → `translateToHead`（跟着头骨）
2. `translate(0, -0.5, 0)`：头骨在脖子，8 像素头的顶在本地 Y=-0.5，坐姿底面落到头顶
3. Y 180°，`scale(0.625, -0.625, -0.625)`（森罗 / 原版 CustomHeadLayer 那套翻转）
4. 用 `ItemStackRenderState` 提交

Cosmetic Armor 会在 `LivingEntityRenderer.extractRenderState` 里把外观头塞进 `headItem`。外观槽或原版头槽是玩偶都要清掉 `headItem`，只留我们的层，否则原版 `CustomHeadLayer` 会按 `-0.25` 再画一只（看起来像坐在脖子上）。

`AvatarRendererMixin` 必须打在 `extractRenderState(Avatar, AvatarRenderState, float)`。打在 LivingEntity 桥接方法上不会跑，头上数据设不上。

GeckoLib 默认 `translate(0.5, 0.51, 0.5)` 要留着：`ItemTransform.apply` 末尾固定 `-0.5`，两头对消，原点才还在坐姿底面。不要在 HEAD 里跳过这一段。

## 加一只时核对

1. BB 原点在坐姿底面中心，摆正，GeckoLib 导出 geo+png
2. 拷进 `geckolib/models/block/` 和 `textures/block/`
3. `DollCatalog` 按文件夹顺序加一行
4. 抄一套 items / models / blockstates / loot / 两个 tags / 双语 lang
5. item 模型 parent 必须是 `doll_item`，不要自写 display
6. 进游戏：放下四向、破坏掉自己、创造栏看得到、空中右键戴到头顶且底面坐实、第一人称不挡、物品栏缩略图看得到头饰、对着方块仍能放
7. 若这只是发光灯：再拷 `_glowmask.png`，按 [玩偶发光灯.md](玩偶发光灯.md) 登记，核对右键开关和光影

头上位置不对，先查这只 geo 原点，再动 Java。

## 发光灯（可选）

不是全员必须。现行只有 `alittle_bird_sit`。玩家规则、glowmask、光影管线、再加一只的步骤见 [玩偶发光灯.md](玩偶发光灯.md)。

不要给没 glowmask 的玩偶无条件加发光层。不要用 GeckoLib 默认 `geckolib:pipeline/emissive`。
