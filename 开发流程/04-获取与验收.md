# 阶段 04：获取与验收

把 02 和 03 收成玩家能拿到、能验收的一包。没有独立切片关卡。

## 本阶段目标

每件 v1 内容都有一种原版材料合成；创造栏分两组；按清单玩一遍再算第一版内容冻结。

## 进入条件 / 离开条件

- 进入：`02-玩偶内容.md` 和 `03-时装内容.md` 都已离开（名单和显示名齐）。
- 离开：合成表填完；本文件验收清单全部勾完。之后才能看 `06-家具后续更新.md`。

## 优先级

### P0

- [ ] 每个 v1 玩偶一条合成
- [ ] 每个 v1 时装一条合成
- [ ] 材料只用原版，不发明新矿、新锭
- [ ] 创造栏：玩偶一组、时装一组
- [ ] 简体中文显示名、物品名正确
- [ ] 安装说明列出全部前置（见 00），并写明 Trinkets Updated 在 1.21.11 目前是 beta
- [ ] 装了 JEI：全部 v1 物品在列表里，R 键能看到合成，中文名正确
- [ ] 装了玉：对着放下的玩偶，信息条是中文名 + 本模组名 + 可戴外观头槽，没有未翻译键

### P1

- [ ] 英文语言文件
- [ ] 玉信息条带朝向（例如「朝北」），不挡中文名 P0
- [ ] 有 EMI 时合成同样能查到（不作为兼容承诺）

### P2

## 游玩验收（逐条勾）

前置已按 00 的**玩家必装**装好。验收兼容时开发机再装 **JEI** 和 **玉（Jade）**。不装这两样，玩家仍能玩；装了就必须过下面带 JEI/玉的勾。

- [ ] 创造模式能在「玩偶」分组拿到全部 v1 玩偶
- [ ] 创造模式能在「时装」分组拿到全部 v1 时装
- [ ] 生存里按合成表能做出对应物品
- [ ] 放下玩偶能看清
- [ ] 放置时四个水平朝向与玩家朝向一致（像发射器）
- [ ] 破坏玩偶能收回
- [ ] 玩偶能放进外观头槽，头上看得见，真头盔防御还在
- [ ] 时装放进对应外观槽，看得见，真护甲防御还在
- [ ] 外观头槽里时装帽和玩偶头饰不能同时生效（互斥）
- [ ] 中文名没有未翻译键（`item.xxx.yyy` 那种）
- [ ] 不装家具也玩得完 v1（没有「必须先做展示柜」）
- [ ] JEI 物品列表能搜到全部 v1 玩偶和时装
- [ ] JEI 能查出每件对应合成，产物中文名正确
- [ ] 玉对着放下的玩偶：中文显示名，不是未翻译键
- [ ] 玉信息条能看出这是本模组的玩偶，且提示可戴外观头槽

## 给玩家的安装口径（可直接贴）

需要 Minecraft 1.21.11、Fabric Loader 0.19.5、Fabric API 0.141.6+1.21.11，以及：

1. Trinkets Updated（1.21.11 构建目前是 beta）
2. Cosmetic Armor Updated
3. Cardinal Components API（Cosmetic Armor 在 1.21.11 需要）
4. GeckoLib（玩偶模型显示用；时装贴图不靠它）

时装和玩偶头饰走外观槽，不会顶掉真护甲的防御。

JEI、玉不是必装。想查合成或对着方块看名字时自己装即可。

## 本阶段不做

- 家具合成
- 大型进度树、成就线
- 抽奖、盲盒
- 因为「先做两个试试」而扣住 01 已圈进 v1 的成品

## 验收标准

- 合成表行数 = 02 玩偶数 + 03 时装数
- 游玩验收没有空勾
- 安装说明和 00 前置表一致
