# 阶段 02：玩偶内容

只定义玩家能对玩偶做什么。名单从 01 抄来，这里不发明新玩偶。

## 本阶段目标

把 01 里勾了进 v1 的玩偶，写成可勾选的内容需求。玩法锁死为森罗物语：玩偶的一个子集。

## 进入条件 / 离开条件

- 进入：`01-资产盘点与导入.md` 玩偶表已离开。
- 离开：每个进 v1 的玩偶都有显示名；P0 行为对所有玩偶一视同仁，没有例外清单。

## 玩家能做什么（全员同一套）

参考森罗物语：玩偶，v1 **只收**下面这些：

| 行为 | P0 / 其它 |
| --- | --- |
| 纯方块，能放在世界上 | P0 |
| 放下能看清（小型摆件，占一小块地面或台面） | P0 |
| 破坏后收回 | P0 |
| 放置时按玩家水平朝向转面，四个方向，像发射器 | P0 |
| 能戴在 Cosmetic Armor **外观头槽**；真头盔防御还在 | P0 |
| 创造栏「玩偶」分组里找得到 | P0 |
| 装了玉时，对着放下的玩偶能看到中文名和「可戴外观头槽」 | P0 |
| 装了 JEI 时，该玩偶出现在物品列表，能查出合成 | P0 |
| 抽奖机、盲盒 | 不做 |
| 方块变成可投掷实体 | 不做 |
| 捏捏叫 / 音效互动 | 不做 |
| 360° 微调工具 | 不做 |
| 给玩偶换装 | 不做 |
| 戴进原版头盔槽 | 不做（会牺牲头盔防御） |
| 坐、骑、AI、命名牌玩法 | 不做 |

外观头槽同时只能一件：戴着时装帽子时不能再戴玩偶，反过来一样。写进玩家能理解的规则即可，不解释槽位实现。

## 本阶段不做

- 家具、展示底座
- 自研饰品槽
- 把某一只玩偶做成例外（例如不能戴、不能转）
- 扩大到森罗物语其它系统

## 验收标准

- 表里的行数 = 01 里勾了进 v1 的玩偶数
- P0 行为表没有含糊词（「也许能转」「以后再戴」）
- 头饰口径明确是外观头槽，不是头盔槽
