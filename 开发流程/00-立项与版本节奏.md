# 阶段 00：立项与版本节奏

给之后的 AI 和你自己对着勾。不写代码怎么组织。

## 本阶段目标

钉死玩家在 v1 拿到的是什么、装哪些前置、哪些事现在不准做。

## 进入条件 / 离开条件

- 进入：本文件按共识写完即可开始。仓库可以是空的。
- 离开：下面 P0 全部勾完，才能开 01。

## 一句话定位

先能摆小型方块玩偶、能穿时装。家用原版方块凑。家具不是 v1 卖点。项目可以继续叫 BC's Furnishings & Decor，但 00 之后任何文档都不许把「装修展示空间」写成第一版承诺。

## 玩家必装（写进以后的安装说明）

| 前置 | 用途（给玩家看的口径） |
| --- | --- |
| Minecraft 1.21.11 | 游戏版本 |
| Fabric Loader 0.19.5 | 加载器（口语里的 Fabric 0.19.5） |
| Fabric API 0.141.6+1.21.11 | 常规依赖 |
| Trinkets Updated（Patbox） | 饰品槽；1.21.11 线目前是 beta，说明里写明 |
| Cosmetic Armor Updated | 头/身/腿/脚四个外观槽：只改样子，真护甲数值还在 |
| Cardinal Components API | Cosmetic Armor Updated 在 1.21.11 需要它 |
| GeckoLib | 玩偶（以及以后不规则缩放的家具）用 `.geo.json` 显示；时装贴图本身不用它 |

不自研额外槽位。玩家装一次即可：只要模组里有玩偶，GeckoLib 就是必装，不是「每件时装都要单独依赖」。

选档时一律 **Minecraft 1.21.11 + Fabric Loader 0.19.5 + Fabric API 0.141.6+1.21.11**。Java 21。GeckoLib 用 5.4.x（例如 5.4.5）。Trinkets Updated 的 1.21.11 线目前是 beta，说明里写明。

## 可选兼容（玩家不装也能玩，装了必须信息正确）

JEI 和玉（Jade）**不是**玩家必装。v1 要兼容它们的信息显示：不装照样玩；装了以后查合成、对着方块看名字不能是空的或未翻译键。

| 模组 | 保证什么 |
| --- | --- |
| **JEI**（Just Enough Items，1.21.11 Fabric 有正式档） | 全部 v1 玩偶、时装出现在物品列表；按用途能查出对应合成；显示中文名 |
| **玉（Jade）** | 对着放下的玩偶：中文名、本模组名、能戴外观头槽。时装在物品形态下中文名正确 |

开发验收时把这两样装上，用来勾 04。EMI 有则更好，不作为 v1 兼容承诺。

## 开发时建议装（不写进玩家安装说明）

| 装什么 | 干什么 | 必装？ |
| --- | --- | --- |
| Blockbench 插件 **GeckoLib Models & Animations** | 把不规则缩放的玩偶导出成 `.geo.json` | 做模型时要 |
| **JEI** | 验合成和物品列表 | 验收兼容时要 |
| **玉（Jade）** | 验对着玩偶的信息条 | 验收兼容时要 |
| **Mod Menu** | 看前置有没有漏、以后若有设置页 | 开发机建议 |

v1 没有设置页，**不要**把 Cloth Config 加成玩家前置。真要做开关时再加，并继续用 Mod Menu 当入口。

## 明确不要加（会把开发变重）

- AzureLib：和 GeckoLib 干同一件事，不要双开
- Accessories / 非官方移植：时装槽已经用 Cosmetic Armor Updated
- JsonThings / Filament / KubeJS：换一条内容管线，不是给现有 GeckoLib 玩偶减负
- 坐下类模组：家具波次 A 才需要，现在加等于提前做 06
- Create、Handcrafted 等成品家具模组：本项目是自研内容，不当前置

## 内容清单

v1 交什么（名单本身在 01 入仓后填，这里只锁规则）：

- 玩偶：入仓后所有能摆能戴的成品
- 时装：入仓后所有能穿进外观槽的成品
- 每件都有一条原版材料合成
- 创造栏两组：玩偶、时装
- 装了 JEI / 玉时，合成和方块信息显示正确（见上表）

## 本阶段不做

- NPC / 伴侣玩偶
- 战斗向防具数值
- v1 家具（含底座、架子、小桌当「展示配套」也不做；用原版方块摆）
- 整包选模
- 抽奖机、盲盒、投掷实体、捏捏叫、360° 微调
- 独立「垂直切片」内容阶段
- 软件架构、目录规划、Gradle

## 验收标准

- 任何人只看本文件，能说清 v1 卖什么、不卖什么、玩家还要装什么
- 没有「家装成可逛展示空间」这种 v1 假承诺
